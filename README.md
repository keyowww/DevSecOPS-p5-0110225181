# Simple Python Calculator (DevSecOps Project)

## 1. Nama Aplikasi & Fungsi
Aplikasi ini adalah **Simple Python Calculator**, sebuah aplikasi CLI (Command Line Interface) berbasis Python yang berfungsi untuk melakukan operasi matematika dasar serta menyediakan fungsi pengujian unit (unit test).

## 2. Bahasa & Framework
- **Bahasa Pemrograman**: Python 3.10+
- **Testing Framework**: `pytest`
- **SAST Security Tool**: `bandit`
